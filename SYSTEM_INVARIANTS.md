# Системные инварианты VK to iOS Notifier

Критические архитектурные правила и незыблемые ограничения проекта:

1. **Веб-автоматизация вместо VK API (Паттерн доступа)**:
   - ВКонтакте жестко блокирует сторонние токены (`Flood Control (code: 9)`).
   - Токены официального приложения VK Admin имеют суточный TTL (24 часа) и привязаны к сессионному IP (`code: 1130`).
   - Получение сообщений работает исключительно через эмуляцию реального веб-клиента `vk.ru/im` в Playwright (headless Chromium).

2. **Приватность и секреты**:
   - `session.json` содержит активные cookies и storage state авторизованного профиля VK. **Никогда** не должен фиксироваться в системе контроля версий.
   - `.env` содержит персональный ключ `BARK_KEY`. Должен быть в `.gitignore`.

3. **Защита от дубликатов пушей при перезапуске (`seen_cache.json`)**:
   - Состояние последних сообщений сохраняется на диск в `seen_cache.json`.
   - При старте и рестарте службы кэш подгружается, исключая повторную отправку уведомлений по уже прочитанным или старым сообщениям.

4. **Сертификаты и проверки безопасности**:
   - Для работы с доменами `vk.ru` и `id.vk.com` требуются установленные системные корневые сертификаты Минцифры РФ.
   - Скрипты `qr_auth.py` и `web_notifier.py` обязаны обрабатывать промежуточные шлюзы проверки («Проверяем, что вы не робот») нажатием кнопки «Продолжить».

5. **Правила парсинга и анти-спам**:
   - Статус «печатает...» (`TYPING_COOLDOWN_SEC = 180`) отправляется не чаще одного раза в 3 минуты на каждый диалог.
   - Относительные таймштампы (`· 1м`, `· 5м`, `только что` и т.д.) отсекаются, чтобы не триггерить ложные изменения текста сообщений.
   - Сообщения, начинающиеся с `Вы: `, игнорируются (исходящие от самого пользователя).
