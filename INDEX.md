# Индекс документации проекта (vk-ios-notifier)

Центральный навигатор по документации репозитория для разработчиков и AI-агентов.

| Документ | Назначение / Содержание | Когда читать агенту (Триггер) |
|---|---|---|
| [README.md](README.md) | Общее описание сервиса, архитектура, системные требования, пошаговая установка, авторизация через QR и настройка Bark / systemd. | Первичное ознакомление с проектом, инструкции для пользователей, деплой. |
| [AGENTS.md](AGENTS.md) | Локальные правила для агентов: стек, команды управления, структура файлов, ключевые табу. | Перед внесением изменений в код или выполнением команд в репозитории. |
| [SYSTEM_INVARIANTS.md](SYSTEM_INVARIANTS.md) | Незыблемые архитектурные правила: причины отказа от VK API в пользу Playwright, жизненный цикл сессии, кэш сообщений, сертификаты Минцифры. | Перед рефакторингом, изменением сетевой логики, авторизации или обработки сообщений. |
| [.context/FREEZE_HYPOTHESES.md](.context/FREEZE_HYPOTHESES.md) | Анализ антифрода VK Protect, детекта «вирусы/взлом», фингерпринтов железа и причин заморозки сессий. | При инцидентах блокировки аккаунта, настройке прокси или обновлении антидетекта. |
| [.context/LIGHTWEIGHT_LONGPOLL_RFC.md](.context/LIGHTWEIGHT_LONGPOLL_RFC.md) | Архитектурный план перехода на легковесный демон (aiohttp / Web LongPoll) без Chromium с потреблением ~20 МБ RAM. | При оптимизации ресурсов, отказе от Playwright или разработке быстрого клиента. |
| [longpoll_client/README.md](longpoll_client/README.md) | Альтернативный легковесный демон на Web LongPoll (aiohttp ~20 МБ): архитектура, авторизация, запуск. | При исследовании или переключении на легковесный LongPoll-клиент. |
| [tests/](tests/) | Интеграционные и E2E тесты (прокси, IP-чекер, Bark шлюз, живая сессия Chromium, дедупликация). | При валидации изменений, тестировании сети или регрессионном аудите. |
